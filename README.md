Assignment 2 - A description of GitHub

First select "new repository" on Github.
Then create a branch, when you add a new feature it gets added to a branch. The definitive branch is called main.

Then you can commit changes, which is saving changes. Pull requests compare your changes to the original before committing. When you commit a change, it is called a merge. 

Git vs GitHub
Git is the control system used to manage and track code changes and it is installed and run on your local machine. GitHub manages Git repositories, and is hosted on the web. Both of them work together on your laptop to manage your code.  

Webstorm
First download WebStorm from https://www.jetbrains.com/webstorm/download/?section=windows. Then you can either create a new project or open an exisitng one. You can also clone a repository directly from GitHub. 


**Branch - There is one main branch which is the most current version of the code. Every time you make another branch off the main one, you are making a copy of main as it was in that point.
Clone - creates a copy of a specific repository or branch in a repository. You usually do it at the beginning of the project, such as accessing a repository locally from GitHub
Commit - saves a snapshot of changes into the Git repository, which creates a point in history that tracks and help manage s the project progress.
Fetch - downloads files, commits, and refs from a remote repo into your local repo 
GIT - a version control system used to manage and track code changes and it is installed and run on your local machine
Github - manages Git repositories, and is hosted on the web.
Merge - combines multiple commits into a single branch
Merge Conflict - when multiple developers try to edit the same content, it can cause a conflict to occur, such as changing the same lines of code or deleting a file
Push - uploads your local repo commits to a remote repository  (Github)
Pull - when you have changes in a branch off of main, you can open a pull request where someone reviews your changes and merges them into the branch
Remote - when your repo is stored somewhere outside your local computer. GitHub is an example of this
Repository-  a storage space for code where you can track your projects' files and a complete history of changes**
